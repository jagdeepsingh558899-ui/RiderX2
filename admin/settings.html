⚠ Danger Zone
Resetting settings will restore RiderX admin settings to their default values. This does not delete Firebase users, rides or other application data.
RiderX Admin settings are currently stored locally in this browser. These controls must be connected to a secure server-side/Firebase admin configuration before they are treated as global platform settings.
